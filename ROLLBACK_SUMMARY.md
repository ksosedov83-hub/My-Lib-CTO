## ❌ Проблемы, которые были исправлены

### PR #17 - Кеширование материалов БЕЗ opacity
**Проблема:** Материалы кешировались по ключу цвета без учета opacity. При изменении фильтра opacity обновлялся динамически через `material.opacity = ...` и `material.needsUpdate = true`, но Three.js не всегда корректно перерисовывал узлы.

**Было:**
```typescript
const materialKey = `phong-${graphNode.color}`;
const material = getCachedMaterial(materialKey, () => ...);
material.opacity = opacity;
material.needsUpdate = true;
```

**Стало:**
```typescript
// Создаем материал заново с правильным opacity
const material = new THREE.MeshLambertMaterial({
  color: color,
  opacity: opacity, // вшит изначально
});
```

### PR #18 - Принудительное обновление графа через useEffect
**Проблема:** Был добавлен useEffect, который при изменении selectedThemes принудительно обновлял граф через `graphRef.current.graphData({nodes: [...currentData.nodes], ...})`. Это вызывало черный экран и ошибки.

**Было:**
```typescript
useEffect(() => {
  if (graphRef.current) {
    const currentData = graphRef.current.graphData();
    graphRef.current.graphData({
      nodes: [...currentData.nodes],
      links: currentData.links,
    });
  }
  // ... autofocus logic
}, [selectedThemes, ...]);
```

**Стало:**
```typescript
useEffect(() => {
  // Только autofocus, без принудительного обновления графа
  if (selectedThemes.length > 0) {
    // ... autofocus logic
  }
}, [selectedThemes, ...]);
```

## 🔑 Новая философия фильтрации

### Старый подход (НЕ РАБОТАЛ):
1. Кешировать материалы по цвету
2. Менять opacity динамически
3. Полагаться на `material.needsUpdate`
4. Принудительно обновлять граф через `graphData()`

### Новый подход (ПРОСТОЙ И РАБОТАЕТ):
1. Кешировать ТОЛЬКО геометрию (не меняется)
2. Материалы создавать ЗАНОВО для каждого узла
3. Opacity вшит в материал изначально
4. Three.js сам оптимизирует одинаковые материалы
5. React-force-graph-3d сам управляет обновлением узлов
